How to make grid cells editable, with validation

Twelve stock items below have two editable columns: Quantity, which must stay between 0 and 500, and Owner, which cannot be blank. Double-click a cell, or focus it and press Enter, to edit it. A value that breaks its rule is refused, the old value stays and the cell is marked invalid; an accepted edit is logged beneath the grid. Read the full how-to on latticegrid.dev.
